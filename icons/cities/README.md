# Иконки городов

Общая библиотека для карт всех выпусков. Пополняется по мере выхода новых серий.

Правила, чтобы иконки были одного стиля:
- холст 64×64 (`viewBox="0 0 64 64"`), основание — полоса на y=54–58, силуэт вписан в поле 6–58 по ширине;
- контур `#1c1b1a` толщиной 2, скруглённые стыки; заливки плоские, без градиентов и теней;
- палитра: камень `#efe4cb`, тень `#cdbd9c`, терракота `#b5553a`, синяя глазурь `#3f7f8f`, золото `#d9a441` (не больше трёх цветов на иконку, кроме контура);
- одна узнаваемая постройка на город, без текста;
- имя файла — название города латиницей в нижнем регистре.
