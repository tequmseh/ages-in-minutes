# Иконки городов

Общая библиотека для карт всех выпусков. Пополняется по мере выхода новых серий.

Стиль: сплошной силуэт одного цвета, детали вырезаны (сквозь них виден фон карты).

Правила, чтобы иконки были одного стиля:
- холст 96×96 (`viewBox="0 0 96 96"`), общее основание — полоса на y=86–90 или ступени до y=87;
- один цвет `#1c1b1a`, рисунок задаётся маской: белое в маске — тело силуэта, чёрное — вырез; обводок и градиентов нет;
- самая тонкая деталь не уже 0,9 единицы, иначе на карте пропадает;
- одна узнаваемая постройка на город, без текста и без людей;
- имя файла — название города латиницей в нижнем регистре;
- чтобы перекрасить, меняется один атрибут `fill` у последнего прямоугольника.
